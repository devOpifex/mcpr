# Create a JSON-RPC 2.0 error response

Create a JSON-RPC 2.0 error response

## Usage

``` r
create_error(code, message, data = NULL, id = NULL)
```

## Arguments

- code:

  Error code

- message:

  Error message

- data:

  Optional error data

- id:

  Request identifier

## Value

A structured JSON-RPC 2.0 error response
