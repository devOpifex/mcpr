# Process blocks for MCP roclet

Process blocks for MCP roclet

## Usage

``` r
# S3 method for class 'roclet_mcp'
roclet_process(x, blocks, env, base_path)
```

## Arguments

- x:

  MCP roclet object

- blocks:

  List of roxy_block objects

- env:

  Environment

- base_path:

  Base path

## Value

List of processed MCP tools
