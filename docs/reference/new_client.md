# Create a new mcp client

Create a new mcp client

## Usage

``` r
new_client(command, args = character(), name = command, version = "1.0.0")
```

## Arguments

- command:

  The command to run

- args:

  Arguments to pass to the command

- name:

  The name of the client

- version:

  The version of the client

## Value

A new mcp client
