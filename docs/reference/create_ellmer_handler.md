# Create an ellmer handler function for an MCP tool

Create an ellmer handler function for an MCP tool

## Usage

``` r
create_ellmer_handler(client, tool_name, input_schema)
```

## Arguments

- client:

  The mcpr client

- tool_name:

  The name of the MCP tool

- input_schema:

  The tool's input schema

## Value

A function that can be used as an ellmer tool handler
